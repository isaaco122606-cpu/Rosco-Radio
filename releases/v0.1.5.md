# Rosco Radio v0.1.5 Stable

Rosco Radio v0.1.5 promotes the Achievements build to the stable channel.

## Highlights
- Achievements system promoted to Stable.
- Includes achievement tracking for RX, CW, VOX, serial PTT, UTC announcements, RR AI chaos, CB bait, and completing the Chocolate Broadcast.
- Built for the standalone Windows channel through NexusUpdater.

## Update channel
- Channel: `stable`
- Target version: `0.1.5`

> NexusUpdater's `rosco-radio` stable manifest must also report `0.1.5` for standalone clients to receive the update correctly.
