# Rosco Radio v0.1.2 — Stable

This is the current recommended Rosco Radio release.

## Highlights

- Redesigned WebSDR workspace with the receiver page on the left and receiver data on the right.
- Fixed WebSDR frequency/action control sizing.
- CW workspace now places Automatic Morse TX on the left and decoded CW on the right.
- CW receive-engine controls moved behind the settings gear.
- SSTV workspace now places the decoded image on the left and receive engine on the right.
- Local Radio now requires an explicit service selection.
- FRS supports VOX and Serial PTT configuration.
- Ham and GMRS expose station-identity controls.
- CB currently reports that it is unsupported.
- RX decoder-bus configuration moved behind compact settings controls.
- Fixed First Time Setup so first launch is tracked per Windows user under `%APPDATA%\RoscoRadio`.
- NexusUpdater now compares versions correctly, verifies update hashes, stages installs, and keeps rollback backups.

## Install

You can use either the full release ZIP or the small **Rosco Radio Online Installer** included with this release. The online installer queries NexusUpdater, downloads the current Stable package, verifies its SHA-256, installs it for the current Windows user, and launches RR.

## Update service

NexusUpdater endpoint: `https://nexusupdater.duckdns.org`
