# Rosco Radio v0.1.3 — Beta

This prerelease contains everything in Stable v0.1.2 plus the new Rosco Radio **Satellite** workspace.

## Beta additions

- Native RR-styled Satellite workspace.
- Embedded SatDump processing runtime in the packaged Beta build.
- SDR hardware probing from inside Rosco Radio.
- Satellite recording/pipeline processing without exposing the standalone SatDump UI.
- Satellite output stored under the Rosco Radio storage directory.

## Shared UI / reliability fixes

- Redesigned WebSDR workspace and corrected action-control sizing.
- CW Automatic Morse TX on the left and decoded CW on the right.
- SSTV decoded image on the left and receive engine on the right.
- Local Radio service selection and compact RX decoder-bus settings.
- First Time Setup state is now per Windows user under `%APPDATA%\RoscoRadio`.
- NexusUpdater version checking, SHA-256 verification, staging, and rollback backups.

## Install

The release includes the full Beta ZIP and the small **Rosco Radio Online Installer**. Run the installer with the `beta` channel to pull the latest Beta package from NexusUpdater.

## Third-party software

The packaged Beta includes SatDump as an embedded processing backend. SatDump is GPL-3.0 software. See the Beta branch's `SATELLITE_THIRD_PARTY_NOTICE.txt` and `SATELLITE_ENGINE.md` files for integration and licensing information.
